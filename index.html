Malik Setup

Malik Code kya hai? Agar koi SR apna PIN bhool jaye, to aap ye code daal kar uska naya PIN banwa sakte hain. Uska data aur history nahi mitegi.
Ye setup sirf aap (malik) ek dafa karein, SR ko na dikhayein.
Malik Code file mein laga hua hai. Sab phones par "PIN bhool gaye?" ab Malik Code maangega.
Ab GitHub par:
1. Apni repo mein index.html kholein ? ?? (Edit) dabayein.
2. Ctrl+F se MALIK SETTINGS dhoondein.
3. Neeche ki 2 lines (const FIREBASE_CONFIG_ENC aur const MALIK_CODE_HASH) mita kar ye copy ki hui lines paste karein.
4. Commit changes dabayein. 1-2 minute mein sab phones par lag jayega.

Is phone par Firebase config nahi mila, is liye config khali rahegi. Pehle Menu ? Cloud Sync mein config jorein, phir dobara banayein.
